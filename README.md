## 📱 教學使用指引

* **課堂投影 / QR Code**：可直接將上述任何一個網址製作成 QR Code 供學生用平板或手機掃描操作。
* **各單元獨立運作**：各版本皆具備獨立網址，可單獨提供給學生，亦可透過總目錄自由瀏覽。
* **回首頁導航**：各單元選單與模擬均已配置「🏠 回總目錄」按鈕，方便隨時切換主題。
